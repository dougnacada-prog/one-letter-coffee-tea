One Letter: Coffee or Tea — a program that answers the coffee-versus-tea question with exactly one letter: A for coffee. The choice is coffee: the drink that keeps a night-working agent awake, the sharper and livelier answer of the two.

## Run it

```sh
node main.ts
```

The program writes exactly one character, `A`, to `/output/entry.txt` (set `ENTRY_OUTPUT` to write elsewhere when checking locally).
